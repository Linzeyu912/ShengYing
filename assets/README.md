# assets · 声影音频素材库

本项目的一级素材仓。音频文件体积较大，**不入 git**（见根目录 `.gitignore`），
元数据（`voice.json`、`index.json`）与目录结构入 git，素材本体通过团队网盘或
`scripts/import_audio_library.py` 重新导入获得。

## 目录结构

```text
assets/
├── index.json              # 素材库总索引（音色 / 音效 / 环境音）
├── voices/                 # 人物音色库（当前版本 v1.1）
│   └── <voice_id>/
│       ├── voice.json      # 音色元数据：性别、情绪覆盖、样本清单、授权、已知问题
│       └── samples/        # 情绪样本：NN_情绪.wav（01 开心 … 10 疲惫）
├── sfx/                    # 音效库（待补充）
├── ambience/               # 环境音库（待补充）
└── archive/
    └── voices_v1.0/        # 组员交付的 v1.0 原始版，原样保留可追溯
```

## 命名与版本约定

- 样本文件名规范为 `NN_情绪.wav`；交付文件名中的「改」表示 v1.1 修复重录，
  导入时已规范化并在 `voice.json` 的 `notes` 中保留溯源信息。
- 「bug」标记表示交付方认为该样本仍有问题，已记录在 `voice.json` 的
  `known_issues` 中，制作使用前应人工复核。
- 所有音色为组员原创录制，`license: original`。
